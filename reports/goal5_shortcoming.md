# Goal 5 shortcoming assessment — development evidence only

The strongest supported issue is **criterion mismatch**, which the planned safety-matched baseline B already addresses. No new C mechanism is selected.

The fixed BERT-Mini experiment used a common train-only A8 calibration, the same 16 W4/W8 groups and selected FP checkpoint, 16 independent W8-to-W4 interventions, two informative pairs and exactly one epoch of QAT for each uniform anchor. Thresholds were fitted on a separate benign search subset. All uniform, single-group and pair variants retained all 2,738 observed scoring attacks at the primary refitted operating point. Thus the development evidence supplies no attack-recall failure for a new precision-protection method to repair.

Ordinary document accuracy at threshold 0.5 does not settle the desired low-FPR behavior. For example, lowering layer0 FFN output and lowering layer1 FFN input both yield 99.9513% ordinary accuracy, but yield 22 and 14 false positives after refitting, respectively. The 16 single-group maps span 14–25 false positives out of 1,369 benign scoring documents. Descriptive rank correlations with this FP count are 0.264 for ordinary error, 0.396 for BCE change and −0.177 for logit MSE. These comparisons are dependent, single-checkpoint observations, not significance tests. The selected Quasar-ViT adaptation's conventional objective is accuracy; neither BCE nor these diagnostics should be mislabeled its published ranking rule.

B should therefore enforce FPR≤1% and recall≥FP−1 percentage point while candidates enter its eligible/elite sets, retaining A's evolutionary and shared-engine allocation principles. Filtering only A's final output would not implement B. This is the preregistered A-to-B task adaptation, not a proposed contribution.

The pair lowering layer0 FFN input and layer3 QKV produced 13 false positives after refitting, versus 18 for W8 PTQ; all attack recall remained 1.0. Its fixed-W8-threshold count was 34, showing why score shifts and refitting must be separated. A nonlinear pair effect alone is established prior art, and this observation neither identifies a failure of B nor supports a novel interaction mechanism. Ordinary high-precision preservation is not demonstrably necessary: there are no new misses, and uniform W8 QAT already meets the empirical development constraint with 13/1,369 FP. The original FP32 reference did not receive the extra training epoch, so W8 QAT versus FP32 is not a causal quantization-only comparison. Uniform W4 QAT gives 20/1,369 FP under the same one-epoch QAT allowance; this does not prove that W4 cannot work under all training/calibration procedures.

The remaining possible cost issue is factual but unquantified: embeddings and other fixed FP32 work dominate the logical payload, and packing plus complete non-linear/attention/transfer costs may dominate a shared FPGA engine. No allocated part, target-specific synthesis or board timing yet establishes that bottleneck. Original Quasar A6 packing cannot be transferred as an A8 measurement, and CPU-offloaded nonlinear work cannot be counted as a complete detector FPGA implementation.

The next evidence needed is Goal 4's actual shared-engine cost table followed by hardware-grounded A/B selection. C stays null until a concrete B limitation is demonstrated. If no such limitation emerges, report useful task adaptation and the negative H1 observation without claiming a new allocation method.
