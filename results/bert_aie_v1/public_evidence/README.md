It contains no task calibration/confirmation scores, outcome analyses, final matched timing comparisons, private principal report or sibling outcomes. FIT-derived scales and aggregate FIT/synthetic numerical errors are included; per-input classifier logits/probabilities are omitted. The preconfirmation freeze contains only nominated identities, policies and hash references; it contains no computed holdout threshold or score.

The frozen export manifest is byte-preserved and must be read with its semantic erratum: actual document scoring uses maximum raw logit margin.

Native costs are allocation/two-frame facts, not whole-model latency. Completed original resident/external HLS records are included under `hls_original/`, with original XO hashes/sizes but no large binaries. Active/retry HLS and link artifacts are intentionally absent. No scientific novelty, end-to-end hardware performance, deployment safety or physical validation is established by this package.
